## 基础设施行为

- 同一 Run 的相同请求只发送一次；成功响应在可配置 TTL 内可跨相邻 Run 复用。
- HTTP 超时、网络错误、`408/429/5xx` 执行有限指数退避；错误摘要只保留稳定错误码，不含查询或 URL 参数。
- 每个公网 Provider 使用可配置出站代理、超时、重试、最小请求间隔、缓存 TTL 和最大响应体；CloudDrive2 使用独立 gRPC 配置，不继承公网 HTTP 代理。
- 正常空结果记成功；HTTP、挑战页和结构变化分别记失败。一个来源失败不会取消其他来源，也不会自动禁用来源。
- `source_health` 保存最近检查/成功时间、延迟、数量、连续失败和最近错误；下一次成功将连续失败归零。
- 单条候选损坏时跳过该条；存在条目但全部无法形成合法 v1 BTIH 时明确报告 `invalid_candidate_data`。
